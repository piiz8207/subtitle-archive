# Subtitle Archive

This repository as an archive for Indonesian subtitle files for fansub projects featured on [Lorrainime](https://lorrainime.blogspot.com/).

## Playback & Synchronization
* Use media players powered by modern libass/VSFilter renderers (such as **mpv**, **MPC-BE**, or **MPC-HC**).
* Subtitles are generally timed against specific Web-Rip or BD-Rip releases.
